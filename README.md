# Expense & Budget Visualizer

A mobile-friendly web app to track daily spending. Built with HTML, CSS,
and vanilla JavaScript. Data is stored in the browser with Local Storage.

**Live demo:** (https://mukhamadkalwani11025.github.io/CodingCamp-23November26-Mukhamad_Kalwani/)

## Features
- Add transactions (item name, amount, category: Food, Transport, Fun) with validation
- Scrollable transaction list with delete
- Total balance that updates automatically
- Pie chart of spending by category (Chart.js)
- Optional challenges: dark/light mode, sort transactions, spending limit highlight

## Project structure
- `index.html` — page structure
- `css/style.css` — styles
- `js/script.js` — app logic

## How to run
Open `index.html` in a modern browser. No build step or server needed.
